# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in Audio Lab, please report it privately using **GitHub's Security Advisories**:

1. Go to the [Security tab](https://github.com/Bloomy52/audio-lab/security) of this repository
2. Click "Report a vulnerability"
3. Provide details about the vulnerability

**Please do NOT create a public issue for security vulnerabilities.**

This allows us to work on a fix and coordinate disclosure before the vulnerability is made public.

## Privacy & Data Handling

This application processes all audio files locally in your browser. No data leaves your device.

## Supported Versions

Only the latest version is actively maintained. Please upgrade to the latest version for security patches.
